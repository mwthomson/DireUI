# Rust server with an HTMX frontend

DireUI needs to run comfortably alongside Direwolf on resource-constrained hardware (commonly a Raspberry Pi at a radio site), and the "easy" pitch extends to installation, not just the UI itself. We chose a Rust server serving a server-rendered, HTMX-driven frontend over a Python/Node server with a JS framework frontend. Rust compiles to a single static binary with no runtime interpreter to install, giving a copy-and-run deployment story that fits the Pi/headless-install case well; HTMX keeps the frontend to server-rendered HTML partials with no SPA build toolchain, matching the low-footprint, low-friction goal on both the server and client side. The trade-off is slower initial development velocity and a smaller web-framework ecosystem than Python or Node, accepted for the deployment and runtime-footprint win.
